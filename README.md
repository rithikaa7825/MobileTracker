# 📱 MOBITRACKER

MOBITRACKER is a **Mobile Service Management System** developed to simplify the workflow of mobile repair shops. It helps service centers manage customer information, track repair progress, maintain service records, calculate repair charges, and notify customers through WhatsApp when the repair is completed.

## 🚀 Features

- Add and manage customer details
- Store mobile device information (Brand, Model, IMEI, etc.)
- Record customer complaints and repair details
- Track service status (Pending, In Progress, Completed)
- Manage technician and delivery details
- Calculate service charges and spare parts cost
- Automatically calculate total bill
- Send WhatsApp notification after repair completion
- View repair history and service status
- Responsive and user-friendly interface

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/MOBITRACKER.git
```

2. Open the project folder.

3. Configure Firebase by adding your Firebase project configuration.

4. Run the project using Live Server or open `index.html` in your browser.

## 📖 Workflow

1. Customer submits a mobile phone.
2. Staff enters customer and device details.
3. Technician updates repair progress.
4. Service status changes from:
   - Pending
   - In Progress
   - Completed
5. Bill is generated.
6. WhatsApp notification is sent to the customer.
7. Customer collects the repaired device.
